# G9 DBMS Assignment 1

This repository stores the Group G9 project bundle so it can be downloaded and continued on another device.

## Download

Download `G9_submission_kit.zip` from this repository and extract it. The ZIP contains the paper source, benchmark code, literature matrix, and project notes.

## Current status

The paper source compiled successfully in the Codex editor. The database performance benchmark has not been run, so the bundle contains no measured performance results or final PDF. The project notes explain what remains before submission.

The project compares a proposed Neo4j and PostgreSQL friends-within-k-hops workload. Run instructions and requirements are in the extracted README and `RUN_ON_LAB_COMPUTER.md`.
